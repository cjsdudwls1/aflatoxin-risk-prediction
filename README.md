# 🌾 아플라톡신 부적합 예측 모델 — 프로젝트 개요

> 곡물·견과류 등 식품의 **아플라톡신(곰팡이독소) 부적합(초과 검출)** 여부를,
> 검사 직전 **50일치 농업기상 시계열 + 검사 메타정보**로 예측하는 딥러닝 모델입니다.
> 식약처/식품안전정보원의 검사 데이터(LIMS)와 공공 농업기상 데이터를 결합해,
> "언제·어디서 온 어떤 식품이 부적합 위험이 높은가"를 선제적으로 가려냅니다.

## 📌 이 공개 레포에 대해

이 저장소는 **포트폴리오 공개용**이라, 원본 작업 폴더에서 아래 항목을 빼고 올렸습니다.
빠뜨린 게 아니라 **의도적인 제외**이며, 코드·실험 기록·재현 경로는 전부 그대로 있습니다.

| `5_문서/논문_FSB/참고논문`, `논문 양식` | 타인 저작물(저널 PDF·학회 서식) |

| `4_데이터수집_모듈/config.yaml` | 공공데이터포털 API 키 포함. `config.example.yaml` 템플릿으로 대체 |

이 한 파일로 **5-fold 전체를 처음부터 재학습**해 `3_최종모델_재현패키지/expected_results/`의 수치를 그대로 재현할 수 있습니다.

## 🎯 문제 정의

- **과제**: 이진 분류(부적합 vs 적합)
- **난이도**: **극단적 클래스 불균형** — 전체 **80,883건 중 부적합은 316건(약 0.39%)**. 1,000건 중 약 4건만 부적합.
- **입력**: ① 검사 직전 **50일 × 기상변수 10종** 시계열 + ② 검사종류·식품유형·산지 등 **표(table)형 메타정보**
- **대표 지표**: **F2-score** — 재현율(Recall)을 정밀도보다 4배 중시. 식품 안전 도메인에서는 **놓침(FN)의 비용이 헛경보(FP)보다 크기** 때문.

## 🏆 최종 모델 (EXP-011) — 핵심 결과

| 구성 | 내용 |
|------|------|
| **모델 구조** | Conv1D → BiLSTM → Attention 하이브리드(시계열) **+** Dense(표형) |
| **불균형 처리** | weighted BCE(class weighting) + 양성만 시계열 증강. **작년의 SMOTE는 제거** |
| **검증 방식** | StratifiedKFold **5-폴드**, 폴드마다 train/val/test 분리, **임계값은 val→test 격리** |
| **학습 환경** | Modal 클라우드 GPU(NVIDIA L4), 약 **33분** |

**성능 (Pooled — 5폴드 test 예측을 전부 합쳐 계산한 대표 수치)**

| F2 | ROC-AUC | PR-AUC | Recall | Precision |
|:--:|:--:|:--:|:--:|:--:|
| **0.229** | **0.657** | **0.110** | **0.237** | **0.199** |

> 혼동행렬(Pooled): **TP 75 / FN 241 / FP 302 / TN 80,265**
> → 실제 부적합 316건 중 **75건을 탐지**(약 1/4)하면서 헛경보를 통제하는 균형점을 학습.
> 극단 불균형(기준선 PR-AUC ≈ 0.0039)에서 "전부 적합"으로 찍으면 Recall은 0이 됩니다.

## 📈 작년 → 올해 : 무엇이 바뀌었나

이 프로젝트에는 **두 세대**가 있습니다. 작년 원 과제(캡스톤)를 올해 **재현성·신뢰성 관점에서 전면 재설계**했습니다.

| 항목 | 작년 모델 | 올해 EXP-011 |
|---|---|---|
| 구조 | LSTM-Attention | **Conv1D 2층** + BiLSTM-Attention |
| 불균형 처리 | SMOTE(합성 오버샘플링) | **class weighting**(합성 없음) |
| 평가 방식 | 단일 train/test 분할 1회 | **StratifiedKFold 5-fold** |
| 임계값 | 고정 0.5 / 사후 0.9 | **검증셋에서만 결정** 후 테스트 적용 |
| Recall | 0.691 | 0.237 |
| F2 | ≈0.485 | 0.229 |
| PR-AUC | 0.32 | 0.124 (fold 평균) |

**"숫자는 작년이 높은데 왜 올해가 더 나은가?"** — 이 프로젝트의 핵심 메시지입니다.

작년의 높은 수치는 재현 가능한 실제 성능이라기보다 **① 데이터 누수 ② SMOTE ③ 단일 분할 ④ 사후 임계값**이 겹친 **과대평가**일 가능성이 큽니다. 실제로 올해 실험 중 한 증강 기법에서 셀 단위 사전확률 누수로 PR-AUC가 **4.8배 부풀려진** 사례를 감사(audit)로 확정했고, 누수를 막은 첫 베이스라인은 PR-AUC 0.013까지 떨어졌습니다.

> **올해의 가치는 "더 높은 숫자"가 아니라 "누수 없이 5-fold로 재현 가능한 정직한 평가"에 있습니다.**
> 자세한 근거는 `2_2026_개선실험/reports/작년대비_성능비교.md` 참조.

**실험 흐름 요약**: EXP-001(정직한 baseline) → EXP-003(Conv1D+BiLSTM) → EXP-008(dropout) → EXP-004 v2(시계열 증강, 누수 수정) → EXP-009(상위 기법 하이브리드) → EXP-010(5-fold CV) → **EXP-011(Conv1D padding causal→same, 최종)** → EXP-012~018(커널 크기 절제실험).

## 💾 데이터 · 재현 안내

- **완전 재현 가능**: 모델 학습에 실제로 쓰인 최종 입력 `df_enhanced.parquet`가 `3_최종모델_재현패키지/data/processed/`에 동봉되어 있습니다. 이 파일 하나로 5-폴드 전부 재학습해 동일 결과를 재현할 수 있습니다.
- **원본 raw 데이터(약 3GB)** 는 용량·비공개 사유로 이 레포에 없습니다. 다만 기상·토양 데이터는 `4_데이터수집_모듈/`(공공데이터포털 OpenAPI 수집기)과 `reproduce_crawl.py`로 **누구나 재수집**할 수 있고, LIMS 검사결과만 기관 제공분이라 대체가 필요합니다. (수집 명세: `1_2025_원과제/2_실험데이터/원본데이터_안내.txt`)
- **데이터 계보**: LIMS 검사결과 Excel + 농업기상 OpenAPI(공공데이터포털, 제공기관 1390802) + 주소→좌표 지오코딩 → 검사일 기준 60일 기상 결합 → 특성공학 → `df_enhanced.parquet`.

## ⚙️ 핵심 사양 (요약)

- **데이터**: 80,883행 × 613열, 양성(부적합) 316건(0.39%) · 시계열 50 timestep × 10 변수 + 표형 메타
- **최종 실험**: `EXP-011_cv5_same_padding` (base: `EXP-010_cv5_hybrid`, 변경점: Conv1D padding `causal → same`)
- **불균형/손실**: weighted BCE(pos_weight ≈ neg/pos), 양성만 시계열 증강
- **교차검증**: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`, val→test 임계값 격리
- **재현 환경**: Python 3.11, TensorFlow 2.15.1, Modal GPU(NVIDIA L4) — 자세한 버전 고정은 재현패키지 `src/requirements.txt`
